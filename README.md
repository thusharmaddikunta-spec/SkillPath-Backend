# SkillPath – Backend

The backend REST API for SkillPath, a student career readiness platform.

## Live Links

- **Frontend:** https://skillpath-frontend-coral.vercel.app/
- **Backend:** https://skillpath-backend-96dk.onrender.com/
- **Students API:** https://skillpath-backend-96dk.onrender.com/api/students

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- REST APIs
- Maven
- Render for backend deployment

## Main Features

- Student CRUD operations
- Student skills management
- Target career management
- Skill-gap analysis
- Database integration
